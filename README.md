# 8-Bit Arithmetic Logic Unit (ALU)

An 8-bit Arithmetic Logic Unit (ALU) implemented in SystemVerilog, featuring registered outputs, synchronous control, and functional verification through a dedicated testbench.

## Overview

This project implements a basic 8-bit ALU designed to perform arithmetic and bitwise logical operations.

The design uses a 9-bit registered output to preserve the carry-out bit generated by arithmetic operations.

### Supported Operations

| Opcode  | Operation | Description          |
| `2'b00` | ADD       | Unsigned addition    | 
| `2'b01` | SUB       | Unsigned subtraction |
| `2'b10` | AND       | Bitwise AND          |
| `2'b11` | OR        | Bitwise OR           |

## Design Features

- 8-bit input operands.
- 9-bit registered result.
- Clock-driven sequential architecture.
- Synchronous reset.
- Enable control for output updates.
- Deterministic operation selection.
- Signed-mode indicator for subtraction result interpretation.

## Verification

A dedicated SystemVerilog testbench was developed to verify the ALU's functionality.

The testbench covers:

- Basic unsigned addition.
- Negative subtraction results.
- Arithmetic overflow into the ninth result bit.
- Bitwise AND and OR operations.
- Output hold behavior when the enable signal is inactive.

Functional simulation was successfully performed using ModelSim/Questa.
